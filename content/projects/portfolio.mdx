A personal portfolio built with the Next.js App Router. Content lives in files rather than a database: profile data in a JSON file, one MDX file per project, and screenshots or demo videos discovered automatically from the public folder.

Main features: a project grid with a detail modal (description, tech stack, documentation), a skills showcase with usage counts per technology, experience and education timelines, a certifications page with issuer logos and automatic verification links, a print-friendly resume page, light and dark themes, and a chatbot that answers questions about the portfolio without any external API.
