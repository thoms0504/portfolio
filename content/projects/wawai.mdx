WAWAI centralises the professional profiles of BPS Lampung employees across every regional office, so CVs and employee data no longer live in separate documents.

Main features: one-click ATS-compliant CV export to PDF and Word, import of SIMPEG data (profile, education, job, rank and training history) with manual fields able to override API values, a searchable employee directory with AI-assisted search and office filters, dynamic and pivot tables, HR management tools (functional positions, workload formation, staff comparison, rotation, promotion history, teams and org-chart export), promotion and training reminders, BPS SSO login, role-based access with full activity logging, and a public API used by other internal apps. Python scrapers bundled with the project collect the SIMPEG data. The app is built on Laravel with a React and Inertia frontend.
