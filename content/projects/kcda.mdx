Dashboard KDA tracks how far each district office has progressed in compiling the annual Kecamatan Dalam Angka publication, using only Google Sheets and Apps Script, with no separate server or database.

Main features: a 10-aspect checklist per sub-district with automatic progress, three access levels (public, district, provincial admin) validated on the server, a province summary with rankings and charts drawn in plain HTML/CSS, and an activity history showing what was done on which date.
