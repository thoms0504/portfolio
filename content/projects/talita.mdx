TALITA is a digital service portal for BPS Provinsi Lampung that replaces manual and WhatsApp-based statistical consultations with one platform the public can use directly.

Main features: an AI chatbot that answers from BPS documents using retrieval-augmented generation (LangChain + Pinecone + Grok) with table-aware PDF retrieval, a curated FAQ base, voice input and rate limiting, Zoom consultation booking with conflict detection, a StackOverflow-style Q&A forum with voting and moderation, real-time 1:1 live support chat with Socket.IO notifications, Google sign-in, and an admin panel for multi-PDF ingestion, user management and analytics. The backend is FastAPI with async SQLAlchemy and Alembic, deployed with Docker Compose behind Nginx.
