EksIm processes Lampung's export and import data and publishes it as standardized dashboards, replacing hand-built tables for each official statistics release (BRS).

Main features: automatic BRS tables for exports, imports and trade balance (m-to-m, y-on-y and c-to-c growth) with formatted Excel and CSV export, a multi-dimensional data explorer (HS 2-digit and 8-digit, port, country and sector filters), three AI agents (xAI Grok) for a data chatbot, policy recommendations, analysis and forecasts, and a one-click report generator, a public BRS portal, and an admin studio that accepts CSV, XLSX and BPS DBF files, cleans and validates them, manages periods and backs up data before each change.
